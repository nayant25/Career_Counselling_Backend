# Career Counselling Backend 🎓

This is the backend for the Career Counselling platform, designed to help students identify their strengths and career paths using psychological tests like IQ, MBTI, MI (Multiple Intelligences), and RIASEC. Built with Spring Boot and MySQL, it serves as the core service layer and API provider for the full application.

---

## 🚀 Features

- ✅ User Registration & Login (with JWT Authentication)
- ✅ Test Flow Management (IQ, MBTI, MI, RIASEC)
- ✅ Question & Answer Submission System
- ✅ Score Calculation & Evaluation Logic
- ✅ Career & College Recommendation Engine
- ✅ Admin CSV Import for Test Questions
- ✅ RESTful API for integration with Frontend
- ✅ PDF Report Generation (Based on Test Completion)
- ✅ Role-based access control (Admin/User)

---
